# 试用验证说明

## 每次修改后的检查

运行 `bun run check`。构建成功后，浏览器扩展管理页刷新扩展，并重新打开分析页。

## 浏览器交互检查

先运行 `bun run dev`，使用明确标记的演示数据检查：

- 点击“先看看演示”：出现本地样例目录，容量栏和通知明确显示演示状态。
- 首页自动分析：文件夹大小按降序显示，空文件夹显示完整 0，未统计文件夹显示待统计。
- 点击课程资料的“查看”：自动读取下一层并查询子文件夹合计，不需要再次点击分析；面包屑和“上一级”可返回。
- 输入名称或路径筛选，再清空：条目恢复，不改变云端状态。
- 切换名称、大小、文件数和子目录数排序：升降序正确，数值排序中未知项始终靠后。
- 切换“全部 / 只看文件夹 / 只看文件”：条目类型正确；表头点击也能切换排序。
- 点击文件类型扩展名：显示当前范围及已读取子目录内的匹配文件，点击清除后恢复普通列表。类型合计不使用文件夹汇总值。
- 空间矩形图与当前筛选列表一致，点击文件夹矩形自动下钻；零值和未知值不绘制，隐藏和再次显示正常。
- 点击“已发现的大文件”：仅列实际读取过的文件，不把官方合计当成文件清单。
- 深度扫描：发现所有样例文件、得到正确合计。
- 扫描时停止：不继续下一次请求；未完成结果不显示完整。
- 导出 CSV：带 UTF-8 BOM，字节数不经过四舍五入，缺失大小为空，危险公式前缀已转义。
- 清除本地记录：界面清空，云端不发生任何操作。

错误路径需要检查：无网盘标签页、未登录、账户切换、单个统计批失败、统计超时、列表分页失败和重复页。引擎与接口单元测试覆盖核心错误路径。

## 真实账户只读验证

使用扩展连接已登录的网盘：

1. 连接后自动分析当前层，比较一个熟悉的文件夹与官方客户端的“详细信息”。比较**原始字节数**，避免 GB / GiB 的单位标签差异。
2. 进入其中一个小目录，做深度扫描；与官方合计比较。
3. 在浏览器中退出或切换账户，确认重新请求受到阻止，不把其他账户的结果写入原账户记录。
4. 关闭来源网盘标签页，确认分析页提示连接问题，不把失败显示为 0。
5. 重新打开分析页连接同一账户，恢复记录后自动分析首页；点击“重新查询”可忽略近期结果并更新。
